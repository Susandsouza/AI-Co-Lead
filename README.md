# 🚀 AI Co-Lead: Intelligent Team Lead Assistant

## 📌 Overview
AI Co-Lead is a web-based intelligent dashboard designed to assist team leads and managers in monitoring team performance, identifying risks, and making data-driven decisions.

---

## 🎯 Key Features

### 📊 Overview Dashboard
- KPI metrics (Employees, Active Work, Completed, Overdue)
- Interactive work distribution graph

### 📈 Work Analytics
- Department-wise workload
- Top performers based on completion rate

### ⚠️ Risk Analysis
- Burnout, Disengagement, Sprint risks
- Interactive graphs with explanations

### 📅 Deadlines & Risks
- Tasks near deadline
- High-risk tasks

### 🆕 New Tasks
- Recently assigned tasks with employee details

### 📊 Progress Tracking
- Task completion %
- Performance trends

### 📞 Meetings Summary
- Department-wise meeting load

### 👥 Team Insights
- Overloaded employees
- Low engagement detection

### 🤖 AI Assistant
- Smart suggestions for managers

---

## 🧠 Intelligent Capabilities
- Detects workload imbalance and disengagement
- Provides actionable recommendations

---

## 🛠️ Tech Stack
- Streamlit
- Python
- Pandas, NumPy
- Plotly
